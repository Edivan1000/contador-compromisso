# Contador de Compromisso

Site estático para GitHub Pages. O arquivo `index.html` já contém HTML, CSS e JavaScript.

## Publicar gratuitamente no GitHub Pages

1. Entre em https://github.com e faça login.
2. Crie um repositório novo. Sugestão de nome: `contador-compromisso`.
3. Selecione **Public** e crie o repositório.
4. Dentro do repositório, escolha **Add file > Upload files**.
5. Envie o arquivo `index.html` desta pasta e confirme em **Commit changes**.
6. Abra **Settings > Pages**.
7. Em **Build and deployment**, escolha **Deploy from a branch**.
8. Em **Branch**, selecione `main` e a pasta `/ (root)`, depois clique em **Save**.
9. Aguarde a publicação. O GitHub mostrará o endereço do site na seção Pages.

O endereço normalmente terá este formato:
`https://SEU-USUARIO.github.io/contador-compromisso/`

## Sobre a contagem

As datas são 10/10/2026 e 19/12/2026. O contador usa a data local do dispositivo que abre a página e atualiza automaticamente enquanto a página está aberta. Ao voltar ao site em outro dia, ele recalcula os números.
